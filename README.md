# # Phishing Detection & Awareness Report

This repository contains an analysis of common phishing tactics used to exploit human error, including credential harvesting and social engineering.

## Overview
This project focuses on identifying phishing indicators, classifying threats, and providing actionable security awareness guidelines to protect users from email-based attacks.

## Case Studies Analyzed
- Microsoft Office 365: Analysis of intimidation tactics and domain spoofing.
- Netflix Billing: Analysis of fake urgency and financial credential harvesting.
- BMO Harris (Banking): Analysis of fear-based social engineering and malicious URL redirection.

## Contents
- `Phishing_Detection_Report.pdf`: Comprehensive awareness report, including case studies, red-flag checklists, and prevention guidelines.

Disclaimer: This project was performed for educational purposes using public phishing examples.
